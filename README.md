# Claude Telegram bot

Прокси между Telegram и Claude Code: пишешь боту промт — он выполняет его через
Claude Agent SDK в изолированной рабочей папке и возвращает результат вместе с
файлами.

## Как это устроено

```
Telegram ──► bot (grammY) ──► Claude Agent SDK ──► claude CLI
                 │                                      │
                 │  workspaces/<chat_id>/               │
                 ├─ inbox/    файлы от пользователя ────┤
                 └─ outbox/   файлы от модели ◄─────────┘
                      │
                      └──► автоматически уходят в Telegram
```

- **Авторизация модели** — через `~/.claude/.credentials.json` (та же подписка,
  что у CLI). Отдельный API-ключ не нужен.
- **Сессии** — одна активная на тему, `session_id` хранится в `data/state.json`
  и передаётся в SDK как `resume`, поэтому контекст живёт между сообщениями.
- **Темы Telegram** — каждая тема в личном чате изолирует сессию, очередь,
  настройки, рабочую папку и файлы. Threaded Mode включается через BotFather.
- **Живой ответ** — текст модели появляется как Telegram draft; нативная кнопка
  Stop прерывает Claude и очищает очередь темы.
- **Каждый промт** запускается отдельным процессом CLI: так бот не течёт по
  памяти и переживает падение отдельной задачи.
- **Права** — `permissionMode: bypassPermissions`. Модель выполняет всё без
  подтверждений, с правами пользователя `deploy`.
- **Доступ** — только Telegram user id из `ALLOWED_USER_IDS` и только в личке.
  Остальные не получают ответа вообще.

## Установка

Нужен Node 24+ и установленный, авторизованный `claude` CLI.

```bash
git clone git@github.com:x3duck/claude-tg-bot.git
cd claude-tg-bot
npm install
cp .env.example .env
# заполнить BOT_TOKEN и ALLOWED_USER_IDS
npm start
```

Автозапуск:

```bash
sudo cp bot.service /etc/systemd/system/claude-bot.service
sudo systemctl daemon-reload
sudo systemctl enable --now claude-bot
journalctl -u claude-bot -f    # или tail -f bot.log
```

## Команды

| Команда | Что делает |
|---|---|
| `/panel` | панель управления текущей темой |
| `/new_topic [название]`, `/rename <название>` | создать или переименовать тему |
| `/delete_topic` | удалить тему, сохранив её рабочие файлы в архиве |
| `/new` | начать новую сессию, забыть контекст |
| `/sessions`, `/resume <n>` | список прошлых сессий и возврат к одной из них |
| `/stop` | прервать текущую задачу и очистить очередь |
| `/model` | переключить модель на лету |
| `/cd <путь>`, `/pwd` | сменить рабочую директорию / показать текущую |
| `/verbose on\|off` | показывать ли ход выполнения |
| `/files`, `/get <n>` | список файлов рабочей папки и выгрузка нужного |
| `/status` | модель, директория, сессия, очередь |
| `/usage` | лимиты подписки (5 ч, неделя) и расход бота по чату |
| `/auth_status`, `/login` | проверить или обновить вход Claude без SSH |

Если `/login` попросит код после подтверждения в браузере, отправь его командой
`/auth_code <код>`. Сообщение с кодом бот сразу удаляет.

## Файлы

- **Туда:** приложи документ или картинку — файл падает в `inbox/`, путь
  подставляется в промт, модель читает его сама. Подпись к файлу = промт.
  Альбомы собираются в одно сообщение. Лимит Bot API на приём — 20 МБ.
- **Обратно:** всё, что модель кладёт в `outbox/`, автоматически уходит в чат
  (об этом ей сказано в системном промте), плюс файлы, которые она явно назвала
  в ответе. Отправленное переезжает в `outbox/.sent/`, чтобы не дублироваться.
  Лимит на отправку — 50 МБ.

Чтобы снять лимиты 20/50 МБ, нужен локальный Bot API server — отдельный демон,
по умолчанию не разворачивается.

## Структура

```
src/
├─ index.ts       грамми-бот: команды, очередь, прогресс, отправка
├─ runner.ts      обёртка над Claude Agent SDK
├─ workspace.ts   рабочие папки, скачивание и сбор файлов
├─ usage.ts       лимиты подписки через OAuth-эндпоинт api.anthropic.com
├─ telegram-md.ts markdown → HTML Telegram, нарезка по лимиту
├─ state.ts       состояние чатов в JSON
└─ config.ts      переменные окружения и константы
```

TypeScript исполняется Node 24 напрямую, сборка не нужна.
Проверка типов: `npm run typecheck`.
